OJE Eclipse Extension

Erster installierbarer Prototyp fuer Eclipse und SAP ADT.

  1. In Eclipse Help → Install New Software… oeffnen.
  2. Die kopierte Adresse als Repository eintragen.
  3. OJE Eclipse Extension auswaehlen und die Installation abschliessen.
  4. Nach dem Neustart Help → OJE Hello World aufrufen.
